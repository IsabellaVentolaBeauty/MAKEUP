# MAKEUP

Site da Isabella Ventola Beauty, publicado no Cloudflare Pages.

- `public/`: arquivos estáticos do site
- `.github/workflows/deploy.yml`: deploy automático a cada push em `main`

## Segredos necessários (GitHub → Settings → Secrets and variables → Actions)

- `CLOUDFLARE_API_TOKEN`: token com permissão *Cloudflare Pages: Edit*
- `CLOUDFLARE_ACCOUNT_ID`: ID da conta Cloudflare
